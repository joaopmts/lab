Airflow Connections
===================

Modelo das connections usadas pelos DAGs. NÃO coloque segredos reais neste arquivo
(ele é versionado). Cadastre-as em Admin > Connections na UI do Airflow, ou via CLI:

  docker compose exec airflow-apiserver airflow connections add <conn_id> ...

------------------------------------------------------------------
spark_default  (já definida automaticamente pelo docker-compose via
                AIRFLOW_CONN_SPARK_DEFAULT — não precisa cadastrar)
------------------------------------------------------------------
Conn Type  Spark
Host       spark://spark-master
Port       7077
Extra
{
  "deploy-mode": "client",
  "spark-binary": "spark-submit"
}

As configurações S3A (endpoint MinIO, path-style, etc.) ficam em
spark/conf/core-site.xml, copiado para as imagens do Spark e do Airflow.
As credenciais vêm de S3A_ACCESS_KEY / S3A_SECRET_KEY do .env
(expostas como AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY nos containers).
Os jars hadoop-aws / aws-java-sdk-bundle já estão em $SPARK_HOME/jars.
